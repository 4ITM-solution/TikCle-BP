BP 리포트 유형별 구성안

CSM 질문 6유형 × 섹션 구성. 각 섹션은 ①답하는 질문 ②데이터 소스 ③표현 형태 ④현재 가용성을 명시한다.

v1 · 2026-07-29 · 7/27 사용성 회의 + 검증된 리포트 3종(릴리이브·내러티브 탐색기·BFCM) 기반 · 혜원님 유형 확정안 나오면 병합
모든 유형의 공통 규격 (구조 DNA) — ①한 줄 요약이 결론을 먼저 말한다 ②정보 나열 대신 대비 구조(A vs B, 승자 vs 반례) ③숫자 옆엔 근거 영상 카드 ④"그래서 뭘 하라"는 공식으로 끝난다 ⑤정직 표기: 데이터 기준일·표본 수·측정 불가(—) 상시 노출 ⑥용도 선택 시 마지막 섹션이 "OO을 위한 제안"으로 변형.

1 · 레퍼런스 탐색

"무엇을 탐색해야 하지?"
쓰는 순간: 가이드라인·브리프 작성 전, 제품 정보가 부족하거나 낯선 카테고리일 때 감 잡기. 가장 실무형 — 출력이 곧 브리프 재료.
섹션답하는 질문데이터표현상태
1한 줄 요약이 풀에서 뭐가 반복적으로 먹히나아래 전체의 요약 (LLM 1회)결론 문장 + 핵심 수치 3개지금 가능
2반복 성과 앵글 Top 5어떤 앵글이 반복적으로 성과 내나내러티브 클러스터 × 반응률·조회 (검증된 조합 계층)앵글 카드 5개 — 각각 대표 영상 2~3편 임베드지금 가능
3참고할 크리에이터 사례어떤 크리에이터를 참고하면 되나크리에이터 프로필 (백분위·티어·스파크 여부)티어별 대표 2명씩 — 영상 + 팔로워·성과지금 가능
4바로 쓸 브리프 힌트훅·포맷·CTA를 뭘로 쓰나영상 태깅 (훅·포맷·CTA·오버레이 문구)표 — 상위 훅 유형 × 예시 문구지금 가능 태깅 표본 고지
원형: 없음(신규 조합) — 단, 전 섹션이 기존 검증 데이터의 재배열이라 리스크 낮음. 스코프 기본값: 카테고리 or 유사 브랜드

2 · 카테고리 이해

"이 시장은 어떻지?"
쓰는 순간: 새 캠페인 시작 전 시장 진단 — 무엇을 해야 하는가 이전에 "어떤 시장인가".
섹션답하는 질문데이터표현상태
1한 줄 요약이 시장의 성격 한 문장아래 종합결론 문장지금 가능
2소비자가 반응하는 것어떤 USP·메시지가 먹히나브랜드별 키 메시지 + 반응 상위 앵글키 메시지 리스트 + 근거 영상선행: 키 메시지 실행 (API 키)
3상위 브랜드 플레이 대비이 시장 승자들은 어떻게 다르게 노나카테고리 내 브랜드별 물량·티어·스파크·BSRA vs B 대비 (BFCM 분류표 축약형)선행: 브랜드-카테고리 매핑
4진입 난이도 판단 근거지금 들어가도 되는 시장인가경쟁 밀도(브랜드 수·주간 영상량)·티어 구조·스파크 비중 분포수치 스트립 + 판단 가이드 문장선행: 카테고리 매핑
⚠️ 정직성 핵심: "시장 전체"가 아니라 적재된 브랜드 풀 기준임을 헤더에 상시 고지 (예: "US 스킨케어 — 적재 브랜드 24개 기준"). 원형: BFCM §3 분류표.

3 · 경쟁사 분석

"경쟁사는 뭘 하고 있지?"
쓰는 순간: 콘텐츠 KPI 전략 수립·경쟁 대응 — "빠르게 따라가서 커버"할 대상 파악.
섹션답하는 질문데이터표현상태
1한 줄 요약경쟁사 대비 우리가 알아야 할 것아래 종합결론 문장지금 가능
2지금 바이럴 중인 것경쟁사가 뭘 바이럴시키고 있나최근 기간 조회 상위 영상 × 앵글 (기간 필터)경쟁사별 열 — 바이럴 영상 카드 + 앵글 라벨지금 가능 데이터 기준일 고지
3시딩 방식 비교물량·티어·스파크를 어떻게 쓰나주간 물량·티어 스택·스파크 비중브랜드 나란히 비교표 (BFCM §5 방식)지금 가능
4따라갈 것 vs 피할 것우리는 뭘 하고 뭘 안 하나위 2·3의 승패 대비공식 — 2열 리스트지금 가능
원형: 경쟁사 앵글 비교 리포트(동수님 요청분) + BFCM 운영 비교표. ⚠️ "지금"의 한계 = 데이터 기준일 — 갱신 요청 버튼과 연동.

4 · SKU·포트폴리오 전략

"무엇을 밀어야 하지?"
쓰는 순간: 분기 캠페인·예산 배분 설계. 이벤트(블프·프라임데이) 선택 시 시즌 플레이 중심으로 변형.
섹션답하는 질문데이터표현상태
1한 줄 요약밀기 전략의 결론아래 종합결론 문장지금 가능
2상위 브랜드 SKU 운용 대비히어로 집중인가 포트폴리오인가SKU별 매출·BSR 분포 + 콘텐츠 언급 SKUA(단일 히어로) vs B(포트폴리오) 대비지금 가능 채널 통합은 SKU 묶음 실행 후
3시즌성 — 이벤트 플레이이벤트 때 뭘 어떻게 밀었나이벤트 전·중·후 물량·티어·BSR (검증 완료)주간 티어 스택 × BSR (BFCM 차트)지금 가능
4추천 SKU 믹스그래서 우리는 뭘 미나위 대비 + 대상 브랜드 SKU 목록제안 표 — SKU × 역할(엔진/서브)지금 가능
원형: BFCM 플레이북 (승자들의 "전 채널 단일 SKU 정렬" 발견이 2번 섹션의 씨앗). 웹 증거(딜·가격) 딥 모드는 v2 옵션.

5 · 콘텐츠 전략

"어떤 콘텐츠가 먹힐까?"
쓰는 순간: 콘텐츠 KPI 달성 전략 — 테스트할 아이디어를 만드는 단계.
섹션답하는 질문데이터표현상태
1한 줄 요약뭘 만들어야 하나아래 종합결론 문장지금 가능
2내러티브별 성과어떤 얘기가 반응·매출을 만드나내러티브 × 반응률 × 샵매출 병치 (쿤달 기준값 검증 완료)내러티브 카드 — 반응·매출 나란히지금 가능
3반응 1위 vs 매출 1위 대비반응 얻는 것과 파는 게 다른가위 데이터의 양극 2개A vs B 대비 + 근거 영상지금 가능
4틱톡샵 vs 비샵 앵글 교차파는 영상과 인지 영상의 앵글이 다른가샵 연동 여부 × 앵글 교차 집계2열 교차표지금 가능
5키 메시지 → 공식반복할 주장·문구는 뭔가키 메시지 (캡션+자막+음성)문구 리스트 + 근거 영상 → 브리프 공식선행: 키 메시지 실행 (API 키)
원형: 내러티브 탐색기 (쿤달 19개 내러티브·기준값 대사 완료 — 6유형 중 데이터 신뢰도 최상).

6 · 인플루언서 방법론

"인플루언서를 어떻게 쓰지?"
쓰는 순간: 캠페인 뼈대(월 물량·티어 구성·스파크 운용) 설계 — 세일즈 제안서에도 그대로 쓰이는 유형.
섹션답하는 질문데이터표현상태
1한 줄 요약이 시장의 시딩 공식 한 문장아래 종합결론 문장지금 가능
2케이스 A vs B광고 중심과 오가닉 중심, 뭐가 다른가풀에서 스파크 비중 양극 브랜드 자동 선정릴리이브식 2케이스 대비 (핑크/블루)지금 가능
3월별 시딩 × 매출 추이물량과 순위가 어떻게 동행하나월별 물량·티어 스택 + BSR막대 × BSR 숫자 차트 + 대표 영상지금 가능
4티어 구성 · 최소 수량티어를 어떻게 섞고 몇 건이 임계인가티어 분포 + 성과 임계 (릴리이브 "월 200건" 방식)티어바 + 임계 콜아웃지금 가능
5공통분모 → 운영 공식그래서 우리 캠페인은 어떻게위 종합운영 지표 표 + 공식지금 가능
원형: 릴리이브 영국 제안서 (사용자·CSM 검증 완료 — "가독성 좋다" 피드백의 그 형식 그대로).

스코프·용도별 변형 규칙

단일 브랜드 — 기본형. 대비는 "이 브랜드 vs 풀 평균" 또는 "이 브랜드의 잘된 것 vs 안 된 것"
브랜드 비교(2~4) — 2번 섹션이 "나란히 비교표"로 확장, 케이스 A/B는 선택 브랜드가 직접 맡음
국가 전체 — 섹션 1 뒤에 "시장 개요 — 브랜드 전체 분류표" 삽입, 소표본 브랜드는 "판정 보류" 분리
카테고리 — 국가와 동일 + 미매핑 브랜드 제외 수 고지 선행: 카테고리 매핑
내부 분석용 — 사실·패턴 중심, 내부 용어 허용
브랜드 제안용 — 제목이 "OO 제안 —"으로, 마지막에 "OO을 위한 제안" 섹션 추가, 어투 외부용
