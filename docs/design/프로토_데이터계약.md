# 프로토 v12 데이터 계약 — 신규 블록별 "어떻게 알아내는가"

> 규칙: 프로토에 그려진 모든 신규 블록은 ①데이터 소스 ②판정 로직 ③비용 ④실패/공백 시 화면 표시가
> 이 표에 정의돼야 구현 배차 가능. 정의 없는 블록은 화면에 못 올라간다.
> (기존 배포판 블록은 코드가 곧 계약이므로 제외 — 신규·픽스처 블록만)

| 블록 (위치) | 소스 | 판정 로직 | 비용 | 실패/공백 시 표시 | 배차 |
|---|---|---|---|---|---|
| **이벤트 윈도우** (A) | promotion_events + 기존 전 테이블 | 등록된 이벤트 날짜로 전(2주)/중/후 구간 WHERE 3회 — 재분석 없음 | $0 | 이벤트 미등록: 빈 상태 + 등록 폼. 광고 수치엔 "관측 시점 하한선" 상시 | 프리셋 시드는 019 기존, 등록 UI = FE |
| **반응률 (댓글/1만뷰)** (B·C 전반) | contents.comments/views | 댓글·좋아요·공유 동시 NULL(카로데이터 유입)과 IG -1은 분모·분자 제외. "측정가능 n/전체 m" 상시 | $0 | 측정가능 0이면 "측정불가" (— 표기, 0 아님) | BE-23 |
| **내러티브×매출 병치** (C 내러티브) | content_clusters × kalodata 영상 GMV | 기존 클러스터 멤버십 + 기존 kdMap(영상 URL→GMV) 합산 — 신규 판정 없음 | $0 | GMV 없는 내러티브 "—" | Stage 1 combo-queries |
| **키 메시지** (C) | 캡션 + vision_tags.overlay_text + ASR | 상투어 사전 제거 → LLM 1회가 "반복 주장 문구 3~5개 + 근거 영상 URL" 산출 → key_stats 저장 | ~$0.1-0.3/케이스 1회 | 미산출 시 탭에 "분석 대기" + 원자료 키워드만 | BE-22 |
| **광고 집행 콘텐츠** (C) | contents.is_ad × 클러스터 | 집행 비중 = 클러스터 내 is_ad 비율 (기존 데이터 집계) | $0 | — | Stage 1 |
| **크리에이터 드로어** (B) | contents 집계 + meta_ads 매칭 | 백분위 = 풀 내 percent_rank(평균뷰). 스파크 편수 = is_ad count. 메타 사용 = 파트너십 라벨(확정)+캡션 대조(후보) | $0 | 메타 대조 미실행 시 "메타 광고 대조 전" | Stage 1 + C7 |
| **원본 후보 배지** (E) | meta_ads body/자막 × contents 캡션/ASR | 텍스트 정규화 후 동일 문구 대조 → 후보. pHash는 2차. **확정 아님을 상시 표기** | $0 (pHash 컴퓨트만) | 후보 없으면 배지 없음 (빈 배지 금지) | BE-30 신규 필요 |
| **브릿지→아마존 랜딩** (E) | meta_ads.link_url → 랜딩 HTML 1회 fetch | 자사 도메인 랜딩만: 페이지 내 버튼 목적지 추출 → 아마존 도메인+어트리뷰션 태그(maas·aa_maas) 발견 시 확정 | $0, 1회 저장 | JS 렌더·접속 불가 시 "자사몰 (버튼 미확인)" | BE-21 (본 로직으로 상세화) |
| **SKU 채널 묶음** (D) | products 이름·용량·이미지 | 토큰+용량 환산 후보 → LLM 쌍 판정 전량(~$0.05) → product_group_id 저장. 자동 검증: 이중 판정+모순 플래그 | ~$0.05 1회 | 판정 전: 채널별 개별 표시 (묶지 않음). 애매 쌍 "추정" 배지+해제 | BE-29 |
| **매칭 근거 열** (E 교집합) | 파트너십 라벨 vs 캡션 대조 | 라벨 = 메타 공식 필드(확정) / 캡션 대조 = 위 원본 후보 로직(후보) | $0 | 후보 단계면 "2차 가공 (후보)" | BE-30과 공유 |
| **변곡점 기간 Top3** (A) | contents (기간 WHERE + 정렬 3종) | 변곡점 월 게시 영상을 조회/댓글/저장 정렬 — 기존 데이터 | $0 | 해당 월 영상 0이면 "해당 월 영상 없음" | Stage 1 |
| **딥 태깅 (중요 3~5%)** | 영상 다운로드 + ffmpeg 컷 + LLM | 대상 자동 선정(매출연결→조회상위→반응 이상치→광고 원본) → 백그라운드 | ~$6-10/케이스 | 딥 전 = 기본 태깅 결과 + "커버 기준" 라벨 | EXP-1 결과로 파라미터 확정 |

## 미정 — 확정 전 결정 필요
- **원본 후보(텍스트 대조)가 별도 배차 없음** → BE-30으로 신규 등록 필요 (E 원본 후보·교집합 근거의 실제 백엔드)
- 키 메시지 상투어 사전의 초기 목록 (BE-22 구현 시 확정)

## 이 문서의 지위
프로토 확정 시 이 계약표가 Stage 1(BE)·FE 지시서의 데이터 명세부가 된다.
계약에 없는 화면 요소를 프로토에 추가하려면 이 표에 행부터 추가한다.
