# FE-8 — 케이스 상세 v12 1:1 구현

## 절대 규칙
1. **프로토 v12 = 정본. 재해석·축소·재배치 금지.** 블록 diff 0이 완료 기준.
2. 데이터가 아직 없는 블록(계약표의 BE-21·22·29·30 대기분)은 **계약표의 "실패/공백 시 표시" 그대로** — 지어내기 금지, 픽스처 금지.
3. 화면 언어: 사용자 언어만. 검수에서 확정된 어휘 준수 — "광고 집행/미집행"(오가닉·gifted 금지), "광고에도 쓰임/사용 없음"(승격 금지), 채널 명시("스파크애즈"/"메타 광고" — "광고" 단독 금지), 별표·이모지·기능나열 부제 금지.
4. 텍스트 3종 규칙: 모든 고정 텍스트는 ①질문 ②답 ③출처/한계 중 하나. 같은 정보 두 곳 금지.

## 구현 순서 (커밋 단위)
1. **헤더 통합** — 5줄→2줄 (다크 스트립: brand·채택배지·tier·상태·액션 / 유틸 행: 기간 필터+최신성+스냅샷). 채널 dot·게이지 행 삭제
2. **데이터·분석 콘솔** — PhaseProgress+PhaseRunsPanel+DataChannelGrid → 접힘 콘솔 1개 (채널 카드+분석 단계+재실행)
3. **A**: KPI 축소(광고 집행/미집행만) · [월간 트렌드|이벤트 윈도우] 탭 · 차트 라인 실측 스케일+축 라벨 · 변곡점 표(행 토글→기간 Top3, 정렬 조회/댓글/저장) · 이벤트 등록 빈 상태+폼
4. **B**: 결론+요약 통합 · 채널 토글에 TT샵 흡수(별도 섹션 삭제) · 언어/활동분포 채널 종속 · 월 select 삭제(전역 기간 필터 일원화) · 명단 기본 10/더보기 50 · 크리에이터 드로어(백분위·스파크 편수·메타 사용 구분)
5. **C**: 탭 6개(내러티브[지표 병치+콜아웃]·키 메시지·월별 추이·티어 교차·태그×매출·광고 집행 콘텐츠) · 채널 토글 탭 행 우측 · 표본 라벨 1곳만
6. **D**: 채널 비교 3카드 → SKU 필터(채널 토글 흡수)+통합 표 상시 → 요약 카드 → 상세 탭 7개(TT샵 분해 포함). SKU 묶음은 BE-29 전까지 채널별 개별 표시
7. **E**: KPI 6열 · 랜딩 분포에 브릿지 행(BE-21 전엔 "자사몰" 유지+"버튼 확인 전" 라벨) · 원본 후보 배지(BE-30 결과 있을 때만) · 교집합 근거 열
8. **표준 영상 카드** 공용 컴포넌트 — 세로 임베드(실제 iframe) + 6지표. 모든 영상 노출 지점 교체
